# 自托管静态站点管理平台 产品设计文档

## 1. 产品定位

面向中小团队与企业的**私有化静态站点托管平台**，提供可视化管理界面与开放 API。平台负责静态资源包的上传、发布、回滚、域名绑定、SPA 回退、SSL 证书与访问控制，通过解析接口与数据面（YARP / Nginx / CDN）解耦。

**一句话定位**：自托管版 Netlify，Web 控制台 + 开放 API 双入口。

## 2. 产品形态

| 形态 | 说明 |
|---|---|
| **管理控制台** | Blazor Web App 构建的可视化界面，供人工操作 |
| **开放 API** | REST 接口，供 CI/CD、数据面、第三方系统调用 |
| **数据面契约** | 解析接口，供 YARP 等反向代理消费元数据 |

## 3. 目标用户与角色

| 角色 | 说明 | 主要入口 |
|---|---|---|
| 平台管理员 | 管理用户、租户、系统配置、存储后端 | 控制台 |
| 站点所有者 | 创建站点、管理域名与 SSL | 控制台 |
| 发布者 | 上传版本、发布、回滚 | 控制台 + API |
| 只读用户 | 查看站点、版本、日志 | 控制台 |
| CI/CD 系统 | 自动上传与发布 | 开放 API |
| 数据面 | 获取路由元数据 | 解析接口 |

## 4. 核心概念

| 概念 | 说明 |
|---|---|
| 站点 | 一个可访问的静态站点，如 `admin.example.com` |
| 项目 | 站点的资源来源，一个项目可服务多个站点 |
| 版本 | 一次上传产生的不可变资源包 |
| 部署 | 将某个版本发布到某个环境 |
| 别名 | 指向版本的命名指针，如 `production`、`preview` |
| 环境 | 生产 / 预览 / 自定义环境 |
| 域名 | 站点绑定的自定义域名 |
| 解析配置 | 数据面消费的最终元数据 |

## 8. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 解析接口 P95 < 50ms；控制台页面首屏 < 2s |
| 可用性 | 控制面可水平扩展；解析接口高可用 |
| 安全 | 上传鉴权、Zip 安全校验、路径穿越防护、强制 HTTPS |
| 可扩展 | 存储后端可替换；数据面契约稳定 |
| 兼容性 | 支持 S3 兼容对象存储、本地文件系统 |
| 可维护 | 结构化日志、审计日志、健康检查、指标暴露 |
| 数据一致性 | 版本不可变；发布原子性；证书续期可靠 |
| 易用性 | 控制台操作路径清晰，关键操作有确认与撤销提示 |

| P2 | 增强功能，按需规划 | 灰度发布、审批、SSO、品牌定制、状态页 |

## 11. 产品差异化定位

| 差异化点 | 说明 |
|---|---|
| **完全自托管** | 数据、资源、元数据全部私有化 |
| **数据面无关** | 通过解析接口解耦，可对接 YARP/Nginx/CDN |
| **双入口** | 可视化管理控制台 + 开放 API |
| **版本不可变** | 版本创建后不可修改，回滚通过指针切换 |
| **多租户** | 支持团队/业务线隔离 |
| **精细权限** | 项目级、站点级、环境级权限控制 |
| **SPA 原生支持** | 回退规则作为一等公民 |
| **自动化 SSL** | 基于 ACME 的全自动证书管理 |
| **CI/CD 友好** | 完整 REST API + CLI + 官方 Action |
